# EMPRISE — règles du dépôt

## État du jeu (fichier public)

Après chaque fonctionnalité intégrée, modifiée ou retirée, mets à jour
`emprise-app/public/etat-du-jeu.txt` dans le même commit : une ligne par
fonctionnalité, français simple, jamais de contenu non annoncé ni de date
future. Ce fichier est la source de vérité de l'avancement du jeu pour les
outils de veille.

Règle de confidentialité du fichier (il est servi publiquement par Vercel) :
n'y mettre que ce qu'un joueur peut déjà voir dans le jeu — jamais le nom d'un
Ordre non révélé, ni date de sortie, ni mécanique encore secrète, ni chiffre
d'équilibrage interne.
